# Green Quran (Android) — Releases

Downloadable builds of [Green Quran](https://quran.sabaoon.dev), a native Android Quran reader
(surah + mushaf page reading, hasanat/progress tracking, friends/leaderboard). Signed-in progress
syncs with the [web app](https://quran.sabaoon.dev).

This repo hosts release artifacts only — the app's source is closed. See each release's
**Assets** for:

- `app-release.apk` — installable directly (enable "install from unknown sources" if sideloading).
- `app-release.aab` — Android App Bundle, the format Play Store distributes from.

Privacy policy: https://quran.sabaoon.dev/settings/privacy
